# 常见故障排查与安全守则 (Troubleshooting & Safety)

本文档汇总了实操调测过程中的安全规范以及常见软硬件故障排查对策。

---

## 一、 实验课安全防范守则

> [!CAUTION]
> 1. **严禁带轮着地直接上电调测**：在初次进行电机测试和调参前，**必须用支架或水杯将小车底盘垫高，使四个驱动轮完全悬空**，防止程序失控“飞车”跌落摔坏 RDK X5 核心板。
> 2. **动力开关随手可及**：始终明确 12V 电机独立供电开关的位置，若遇到无法软件急停的情况，第一时间手动切断电池开关。
> 3. **接线防短路**：插拔杜邦线、USB 线和 FPC 摄像头排线时务必先断电。

---

## 二、 常见故障排查对策表

| 故障现象 | 根因排查 | 解决方案 |
| :--- | :--- | :--- |
| **小车电机不动或无力蜂鸣** | 1. 12V 动力电池开关未开；<br>2. PWM 数值低于启动摩擦死区 | 1. 检查电池绿色端子并确保电池盒开关处于 **ON**；<br>2. 满量程为 3600，若误设为 100~300（仅占 3%~8%）会深陷死区，空转建议调至 **1600~1800**，实跑建议 **2000~2400** |
| **小车电机失控全速狂飙 (飞车)** | 误向 2 线 TT 电机发送了 `$spd:` 闭环速度指令 | TT 电机无编码器脉冲线，PID 积分器因测速为 0 会瞬间打满至 100% 满负荷。**必须立即急停并切换至 `$pwm:` 开环指令** |
| **小车直道剧烈蛇形画龙** | 纠偏差速过大或惯性震荡 | 适当缩小内侧轮与外侧轮 PWM 差值，或增大 `RECENTER_BRAKE_SECONDS` 回中缓冲 |
| **小车急弯冲出黑线** | 转向力矩不足 | 适当增大转向外侧轮 PWM 或执行差速原地自转，适当降低直道基准速度 |
| **DHT11 报 timeout 或 failure** | 物理引脚接错或采样间隔过短 | 确认接在 Pin 37 (GPIO 401)；DHT11 物理刷新周期为 2 秒，标记点间距不宜过密 |
| **摄像头无法捕获图像** | 排线反接、卡扣松动或 I2C 不通 | 断电检查 CAM0 接口排线金手指是否插正压紧；运行 `i2cdetect -y -r 6` 确认 `0x10` 是否存在 |
