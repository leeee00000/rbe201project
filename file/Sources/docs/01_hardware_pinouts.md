# 硬件元件控制规范与电气参数表 (Hardware Pinouts & Specs)

本文档整理自 RBE201TC 智能小车系统底层电气引脚定义与供电规范，所有引脚对应地平线 RDK X5 (Linux Ubuntu 22.04 LTS, aarch64) 接口。

## 二、 物理接口与接线排布细节

### 1. 循迹探头排布对照 (从车头方向看)

```text
       [车头朝前]
  -------------------
  | X1   X2   X3   X4 |
  -------------------
  Pin15 Pin18 Pin16 Pin11
 (最左) (左中) (右中) (最右)
```

- **逻辑定义**：
  - `0`：探头位于黑线之上或悬空（反射红外光极少）
  - `1`：探头位于白色底板之上（反射红外光充足）

### 2. DHT11 引脚映射

- **物理引脚**：RDK X5 40-pin 排针上的 **Pin 37**
- **Linux Sysfs 编号**：`401`（对应 `/sys/class/gpio/gpio401`）
- **供电注意**：DHT11 VCC 接 3.3V (Pin 1)，GND 接 Pin 6。严禁反接导致传感器击穿。

### 3. 电机与驱动板接线

- **通道映射**：
  - `M1`：左前轮
  - `M2`：左后轮
  - `M3`：右前轮
  - `M4`：右后轮
- **供电要点**：
  - 12V 动力电池组插在 Yahboom 驱动板绿色端子上；
  - 电池盒上的拨动开关必须推至 **ON** 档；
  - RDK X5 通过 USB 线与驱动板通信（端口 `/dev/ttyUSB0`）。
