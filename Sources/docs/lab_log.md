## 📅 历史实验实操记录

### [记录 1] 2026-10-09：控制台重构、硬件通路验证与基础功能测试

- **实验目标**：
  解决前期电机失控飞车问题，重构适应 TT 双线减速电机的控制工具，验证各传感器物理通路。
- **实操工作与测试结果**：
  1. **驱动与电机协议根因攻克**：
     - 查明小车配备的 4 个 TT 黄色电机仅有 2 根动力电源线，无编码器脉冲反馈；
     - 严禁发送旧版的 `$spd:` 速度闭环指令（测速为 0 会导致 PID 积分打满飞车暴冲）；
     - 确立规范控制流程：开机必发 `$mtype:4#`，使用开环占空比 `$pwm:M1,M2,M3,M4#`（满量程 `-3600 ~ +3600`）。
  2. **终端交互控制台重构与测试 (`terminal_console.py`)**：
     - 开发并实车运行数字菜单终端控制台，剔除闭环指令；
     - 测试功能：按 `1` 前进、`0` 急停、`w/s/a/d` 点动 1.5 秒微调、`t` 逐个测试通道 1~4 单电机转动；
     - 实测确认通道映射：`M1/M2` 为左侧车轮，`M3/M4` 为右侧车轮。
  3. **机载 Web 控制中心重构与测试 (`web_controller.py`)**：
     - 启动 RDK X5 机载 Web 服务（8080 端口），手机/电脑浏览器访问 `http://172.20.10.2:8080`；
     - 测试功能：按住方向键/WASD 移动（松手即停防撞）、1000~3600 PWM 滑块调速；
     - 实时轮询 4 路红外探头电平并在网页指示灯直观显示；
     - 成功调用 IMX219 摄像头实时拍照并回传网页显示，验证了课程大纲中 Local Web 实时遥测要求。
  4. **摄像头采集通路验证 (`camera_snap.py`)**：
     - 验证 MIPI-CSI CAM0 接口与 I2C-6 通信；
     - 成功调用 `hobot_vio` 捕获 1080P NV12 视频帧并转存为高保真图片 `test_camera.jpg`。
  5. **环境温湿度与循迹传感器独立测试**：
     - 编译并运行 `dht11_rdk_x5_test.c`，验证 GPIO 401 单总线微秒时序与 IPC 机制；
     - 运行 `line_sensor_test.py`，验证 4 路探头在黑白介质下的高低电平响应与可调电位器阈值。

### [记录 3] 2026-10-31：有线/无线通信规范确立与机载双模式视频流全通

- **实操工作与测试结果**：
  1. **明确 Type-C 有线通信电气规范**：
     - 攻克了有线网络连接误区：RDK X5 板载 RJ45 网线口固定为 `192.168.127.10`，而 **Type-C USB RNDIS (usb0) 虚拟网卡接口固定为 `192.168.128.10`**；
     - 电脑端需配置对应网卡静态 IP 为 `192.168.128.1`（掩码 `255.255.255.0`），实测延迟 `<1ms` 稳定通信。
  2. **成功完成个人无线热点激活绑定与 IP 固定**：
     - 在小车板端使用 NetworkManager 成功配对个人手机热点：SSID 为 **`123456`**，密码为 **`12345678`**；
     - 生成持久化无线网络连接配置（UUID: `bfc61d11-fdb5-4f6b-a87d-16ccc4a15ba0`），小车开机即可自动加入热点；
     - 确认当前个人热点分配给小车的无线 IP 为 **`192.168.43.30`**，已将其正式写入 `~/.ssh/config` 与全套文档中。
  3. **理清 B/S 架构下的代码部署与同步工作流**：
     - 彻底明晰了“电脑为开发端母本 (Dev) $\to$ 小车为部署运行端 (Runtime/Server)”的协同逻辑；
     - 通过无线 `scp "E:\...\web_controller.py" sunrise@192.168.43.30:~/RBE201TC/` 实现电脑与小车车端代码的一键部署覆盖。
  4. **机载双模式实时视频流与本地抓拍实测全通 (`web_controller.py`)**：
     - 成功实装 `320x240 @ 18fps` 低延迟 HTTP MJPEG 视频流（实测端到端网络延迟 $< 100\text{ms}$，画面跟手极度流畅）；
     - **极速二值化算力优化验证**：通过直接截取 NV12 原始数据前 1080 行 Y 亮度分量进行 Otsu 大津二值化，免去 CPU 转 BGR 的高额开销；
     - **网页端双模一键切换**：成功在网页上实现【🌈 彩色原图】与【🏁 赛道二值化】的秒级无缝平滑切换；
     - **网页抓拍直接存入电脑本地**：实测通过前端 HTML5 Canvas $\to$ Blob 自动下载机制，点击按钮可直接将 `snap_YYYYMMDD_HHMMSS.jpg` 保存至电脑本机“下载 (Downloads)”目录，彻底免除手动 SCP 拉取照片的繁琐流程；
     - 验证了主服务退出时 `cam.close_cam()` 正确释放 CSI 硬件管道，避免驱动死锁。
